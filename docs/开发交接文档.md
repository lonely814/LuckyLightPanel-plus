# 开发交接文档

> 阅读顺序：先看 [README.md](../README.md)（架构与约束）→ [API.md](../API.md)（后端契约）→ 本文（启动流程与踩坑）。

## 1. 硬约束

`src/types/index.ts` 中与 Lucky 后端契约相关的字段（名称 / 类型）**不可随意改动**，改一个字母就断联。改动必须同步跑 `npm run test:contract`，并在 `tests/contract/schemas.ts` 里同步 zod schema。

实测过的契约偏差：`API.md` 声明 `docker-stats` 有 `memoryPercent` / `networkRx` / `networkTx` / `displayName` / `status` / `iconUrl`，但 `public/backend/docker-stats.json` 实际只有 `containerName` / `state` / `cpuPercent` / `memoryUsage` / `networkRxSpeed` / `networkTxSpeed`。因此 `DockerStat` 里前者全部 `optional`，代码侧用 `percentValue()` / `compactMemory()` 兜底。

## 2. 启动流程（`src/App.vue` onMounted）

顺序不能换：

1. `configStore.loadConfig()` —— 先读 localStorage，旧值经 `normalizeConfig` 迁移。
2. `Promise.all([navStore.loadNavConfig(), navStore.fetchServerConfig()])` → `configStore.applyServerConfig(serverConfig)`。服务器配置**只在本地无配置时生效**（`hasStoredConfig === false`），且 `serverBackgrounds` 非空时禁止覆盖 `background`。
3. 按 `sitesEnabled` / `dockerEnabled` / `luckyServicesEnabled` 并行拉三个数据域。
4. `networkMode` 为 `auto` / `hybrid` 时 `fetchNetworkType()`。
5. 最短展示 500ms 后 `booting.value = false`，再 `syncPolling()`。

轮询由 `watch([currentTab, booting], syncPolling)` + `visibilitychange` 驱动：切 tab 或页面隐藏都会先 `stop` 两个轮询再按需 `start`，不存在真空轮询。

## 3. 属性驱动清单

`document.documentElement` 上被写入的属性：

| 属性 | 来源 | 作用 |
|---|---|---|
| `data-theme` | `configStore.theme` | 切换 `tokens.css` 的主题变量块 |
| `data-layout` | `currentLayout`（按 tab 取 `layout` / `dockerLayout` / `luckyServicesLayout`） | 切换密度令牌 |
| `data-reduce-motion` | `config.detailReduceMotion` | 关掉全部动画/过渡 |
| `data-liquid` | `config.detailLiquid` | 液态玻璃卡片样式 |

内联 CSS 变量：`--text-factor` / `--radius-scale` / `--blur-scale` / `--alpha-scale` / `--card-scale`，均由 `config.detail*` 除以 100 得到。

## 4. 踩坑记录

- **`backdrop-filter` 不支持 `url(#filter)`**。写进 backlog 的「液态玻璃折射」用 SVG `feDisplacementMap` 实现不了：Chromium 不会把 `filter: url(#...)` 作用到 backdrop 采样结果上，`scale` 从 24 调到 400 视觉零变化。当前实现改为高光 + 描边 + 噪点三层叠加。
- **`zoom` 生效范围**。`layoutScale` 用内联 `zoom` 作用在内容容器上（不是 `html`），避免影响 `position: fixed` 的浮层。
- **旧配置不能直接丢**。9 套主题 / 8 种布局到 2 / 2 的映射在 `LEGACY_THEME` / `LEGACY_LAYOUT`，`src/stores/config.test.ts` 有覆盖。新增映射记得同步测试。
- **`GroupSelection` 只允许 `'all' | string[]`**，不再接受单个分组字符串。旧测试传单串会 TS 报错，这是故意的收窄。
- **主题 CSS 里禁止 `[data-theme=x] .类名`**。跨层覆盖会让主题重新知道组件私有 DOM，就是重写前 410 处 `rgba()` 和 71 处 light 补丁的来源。
